# Analyze a job description

Using the posting and my profile:

1. Extract only verified requirements, preferred qualifications, responsibilities, graduation/enrollment constraints, start date, location, and work-authorization language.
2. Classify eligibility as verified, likely, unclear, or ineligible, and explain the evidence.
3. Map each important requirement to existing evidence in my resume repository. Do not invent evidence.
4. Identify the three highest-value resume changes.
5. Recommend A/B/C priority and one next action.
6. Produce a proposed row for `data/applications.csv`, but do not mark it applied.
