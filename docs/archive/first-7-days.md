# First seven days

## Day 1 — Establish the source of truth

- Complete `config/profile.yaml`.
- Add your master resume and three cluster copies under `resumes/`.
- Decide pursuit lanes (`core` / `broad` / `practice`); do not hard-reject on sponsorship alone.
- Add live roles manually **or** apply via Simplify and import CSV into `data/imports/simplify/`.
- Generate the dashboard.

## Day 2 — Resume evidence bank

- Build a master list of projects, work, research, coursework, metrics, technical decisions, and interview stories.
- Produce one stable baseline for `cloud_swe`, `data_ml`, and `health_ai`.

## Day 3 — Search setup

- Create saved searches and alerts on LinkedIn, Handshake, Simplify, Jobright, and selected company career pages.
- Search both 2027-start new-grad roles and internships/off-cycle roles that explicitly fit a December 2026 graduate.

## Day 4 — First application batch

- Apply to 3–5 eligible A/B roles.
- Record the exact resume version and next action for each.

## Day 5 — Networking batch

- Select 5 live A-priority roles.
- Identify 1–3 people per company.
- Send 5 targeted outreach messages and record follow-up dates.

## Day 6 — Interview baseline

- Run a diagnostic coding session.
- Prepare concise stories for project ownership, conflict, failure, ambiguity, and impact.
- Identify the largest technical gap for the target clusters.

## Day 7 — Review

- Generate the dashboard and weekly report.
- Fix missing data and overdue next actions.
- Choose no more than three system changes for the next week.
