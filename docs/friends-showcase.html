Architecture

The pipeline

1 · Overnight

Cursor Automation scrapes US new-grad + internship boards → AI triage → generated/discovery_triage_DATE.csv

2 · Resolve

resolve_apply_url.py turns Jobright links into real Greenhouse / Ashby / Workday URLs when possible

3 · Apply hour

Local queue at localhost:8765 → Open → Simplify autofill → you submit → tick Applied

4 · Weekly

Simplify CSV export → import-simplify reconciles the ledger

Team model

One template · many personal copies

Same engine for everyone. Your job search data never mixes with someone else’s.

Template repo

Scripts, docs, board sources, queue UI — we improve this together

Your fork

Your profile, resumes, evidence bank, applications.csv, Simplify secrets

Pull upstream

You receive engine fixes without rewriting your ledger

PR back upstream

You send script/doc improvements so everyone benefits

How friends help

Pull upstream ≠ contribute

  • Pull = get new scripts/UI from the template
  • Help = change the engine on a branch → open a PR into the template
  • Never PR your passwords, cookies, or personal applications.csv

Classic open-source loop — applied to a private friends toolkit.
