# Daily discovery paste (Exp B)

Paste 10–20 roles from Jobright / LinkedIn / Handshake. One per line:

```text
- Optiver — Graduate Software Engineer (2027 Start) — https://www.optiver.com/...
- Company — Role Title — https://...
```

Then:

```bash
python3 scripts/ingest_discovery_list.py --file jobs/inbox/daily-YYYY-MM-DD.md
```

Do **not** put passwords here.
