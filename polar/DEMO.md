# Demo

A demo should prove one claim. It should not tour features.

The claim I want is this. For the same named job, the same standing
answers, and the same stop-before-Submit rule, a compiled Computer Use
path and a Polar packet spend their time on different things.

This repository does not yet contain that comparison. See
[`EVIDENCE.md`](EVIDENCE.md) C018. Do not record a highlight reel that
pretends otherwise.

## What I would record, 3 to 5 minutes

**Setup, spoken in 20 seconds.** One KEEP. One trusted apply URL or one
Jobright Original Job Post. Fill only. No Submit. No new accounts.

**Act 1, about 90 seconds.** Show the compiled Computer Use sheet and
the lint result. Spawn execute only. Cut when the child starts a
scroll or screenshot loop, or when it finishes the named mutations.
Voiceover names wall time, action count if the transcript is
available, and any human takeover.

**Act 2, about 90 seconds.** Show the Polar packet. Paste it. Polar
opens the same URL class. Autofill once if Simplify is present.
Corrections from the packet. Stop before Submit.

**Act 3, about 60 seconds.** Side-by-side of the two reports.

- Handoff size
- Wall time
- Human interventions
- Auth or account walls
- Fields mutated versus fields only observed
- Final correctness against the packet, including any
  `needs_review` widget

**Close.** Say what the video does not prove. One form. One day. No
Submit. No claim about ATS bot detection.

## Why a fair comparison is not in git today

Twitch Computer Use is a Greenhouse form counted from cloud
transcripts on 2026-09-03. Quantbot Polar is a different Greenhouse
form counted from a Polar report on 2026-09-04. The parent prompts on
Twitch were the anti-pattern the compiler now rejects. Polar never ran
that bad prompt.

Using those two numbers as a benchmark would reward Polar for a better
packet and punish Computer Use for a worse parent. That is a handoff
result, which is interesting, but it is not an executor bakeoff.

## Safety

- Do not Submit.
- Do not create Workday, MyGreenhouse, or other ATS accounts for the
  camera.
- Do not bypass CAPTCHA, 2FA, or bot checks.
- Do not open a sibling requisition if the posting is closed.
- Do not paste passwords, cookies, or 2FA codes into git or the video
  description.
- Prefer a posting I already have a session for, or a form that does
  not require a new account.
- If the only remaining KEEP is a Workday wall, stop at reach. That
  still proves Original Job Post. It does not prove fill.

## If I cannot run Polar in the recording environment

This Cloud Agent VM is not my Mac. Polar is a local Chromium fork.
A cloud-only recording can still show Act 1 and the packet text. It
cannot honestly show Act 2 unless I record on the laptop later.

Until that laptop recording exists, the proof remains the experiment
writeups, not a video.
