# Costs

All prices in USD, checked September 2026. **Verify before you subscribe** — one of the two
paid services in this stack has no public pricing page and raised its price 33% earlier in
2026, so anything you read anywhere (including here) goes stale fast.

---

## The short answer

| | Monthly | What you give up |
|---|---|---|
| **Free path** | **$0** | ~1–2 agent tasks/day, 2 tailored resumes/day. Works, but you can't run 50 applications a day. |
| **Realistic path** | **$50** | Nothing. This is the configuration the reference run used. |
| **Frugal path** | **$20** | Buy the agentic browser only; stay on the job board's free tier and accept its daily credit cap. |
| **Heavy path** | **$60+** | Nothing — you're buying headroom for genuinely high volume. |

A job search runs 2–4 months. **Budget $100–240 total**, not a recurring forever cost. Set a
calendar reminder to cancel; one of these services is reported to have a frustrating
cancellation flow and no refunds.

## Line items

### Agentic browser — Polar

From [polarbrowser.com/pricing](https://polarbrowser.com/pricing), read directly
2026-09-18:

| Plan | Price | Credits |
|---|---|---|
| Free | $0 | 3,000 to start, then +100/day capped at 1,000 |
| **Individual** | **$20/mo** | 10,000/month, top up anytime |
| Teams | $50/seat/mo | 25,000 pooled/seat/month |

Billing is **credit-metered**: longer and more complex tasks cost more, so a Workday
application with account creation costs meaningfully more than a one-page Ashby form. Some
third-party reviews list a "$100/mo Max" tier — that does **not** appear on the official
pricing page, so treat it as unverified.

**Which tier you need.** The free tier's 1,000-credit daily cap is roughly one to two real
tasks per day. A single application is one multi-step task, so free gets you a handful of
applications daily, not fifty. If you're running scheduled batches, you're on Individual.
Note that execution-mode settings (there are Lite / Default / Power modes, plus a faster
response toggle that burns credits quicker) give you real control over spend — run this
workflow in a cheaper mode and the same budget goes further.

### Job source — Jobright

**There is no public pricing page.** `jobright.ai/pricing` returns a 404 and prices appear
only after you create an account, which is why published figures disagree wildly. Multiple
independent reviews converge on these, all reporting a 2026 increase from $29.99 to $39.99:

| Plan | Price | Effective monthly |
|---|---|---|
| Free | $0 | 2 credits/day (resume tailoring, autofill, insider email), reset at midnight, no rollover |
| Turbo weekly | $17.99/wk | ~$72–78 |
| **Turbo monthly** | **$39.99/mo** | $39.99 |
| **Turbo quarterly** | **$89.98–89.99/qtr** | **~$30** ← best value |

Sources, all independently reporting the same figures:
[zPlatform, 2026-09-14](https://zplatform.ai/ai-reviews/jobright-ai/) ·
[Jobity, screenshotted 2026-08-31](https://jobity.io/blog/jobright-review) ·
[Wobo, 2026-07-09](https://www.wobo.ai/blog/jobright-review/) ·
[Resumly, 2026-06-13](https://www.resumly.ai/answers/jobright-review)

**Read this before picking a plan:**

- **Avoid weekly.** At $17.99/week it totals ~$72/month for identical features.
- **Quarterly is the real choice** if you'll search longer than a month — ~$30/month
  effective, a 25% discount on monthly, and a job search almost always runs past 30 days.
- The free tier's **2 credits/day** is the binding constraint. Each application consumes a
  tailored resume and an autofill, so free means ~2 applications per day.
- **No free trial of Turbo, and reviews report no refunds.** You're committing blind, and
  you won't see the price until you've made an account.

## Cost per application

Using the realistic $50/month configuration and the reference run's measured throughput:

| Volume/month | Cost per application |
|---|---|
| 50 | $1.00 |
| 200 | $0.25 |
| 500 | $0.10 |

At even modest volume this lands well under a dollar per application. The comparison that
matters isn't dollars though — it's the ~7 minutes of your own attention per application
that you stop spending. 200 applications is roughly **23 hours** of form-filling.

## Where the real cost is

Not the subscriptions.

1. **Setup: ~45 minutes**, mostly creating accounts and writing your `profile.md`.
2. **The mandatory supervised trial: ~2 hours** for 10+ applications. Skipping this is the
   expensive mistake — you'll ship a false claim to twenty employers before noticing.
3. **Ongoing: ~10 minutes/week** reading the audit output and answering anything escalated.
4. **The tail risk: a fabricated claim reaching an employer.** Unpriceable, and the reason
   the pre-submit checklist exists. Autofill produced five distinct false statements in
   eleven applications during the trial run. The checklist caught all five; nothing else
   would have.

## Cost-control settings

- Use the **quarterly** job-board plan, never weekly.
- Run the agent in a **cheaper execution mode**; this workload doesn't need the expensive one.
- **Cap the daily target.** 50/day burns credits fast and there's no benefit to a 6-hour run
  if your queue only has 40 jobs in it anyway.
- **Turn the schedules off when you stop searching.** Both services bill whether or not you
  run anything.
- Run the free tiers for the first few days to confirm the whole loop works end to end before
  paying for either service.
