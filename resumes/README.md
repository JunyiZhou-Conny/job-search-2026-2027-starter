# Resume architecture

Recommended structure:

- `base/`: complete master evidence resume or long-form source.
- `cloud_swe/`: cloud engineering, platform, backend, infrastructure, and general SWE.
- `data_ml/`: data engineering, analytics, ML engineering, and applied AI.
- `health_ai/`: healthcare technology, clinical/data products, life-science AI, and health analytics.

Use stable version names, for example:

`2026-07-20_cloud-swe_v1.0.tex`

For a specific job, prefer a small patch recorded in the job dossier rather than creating an untraceable full rewrite. After applying, record the exact version in `data/applications.csv`.
